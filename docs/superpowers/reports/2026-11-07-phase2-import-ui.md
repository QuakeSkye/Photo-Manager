# 第二阶段：导入界面重构

日期：2026-11-07。分支：codex/ui-redesign-gemini。基于 f6b8e68。

## 完成内容

- 导入流程分为选择位置、检查计划、执行导入、查看结果；主要操作固定在底栏。
- 来源与目标路径明确展示；技术细节折叠，异常按实际状态提供处理入口。
- 导入计划按新增、跳过、无法读取、同名另存、日期未知查看，展示真实文件名及来源与目标路径。筛选仅改变查看范围，最终确认仍提交完整计划及其 digest。
- 保留更新计划重新确认、来源重选、空间不足、恢复文件隔离、部分完成重试和取消等流程；请求期间防止重复提交，停止状态等待后端确认。
- 完成页展示后端汇总及预检无法读取提示；原计划明确标注，避免冒充逐文件执行结果。
- 返回图库重新读取快照，保留原选片上下文。
