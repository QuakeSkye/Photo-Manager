# 阶段 8 已知限制

> **v1.0.0 历史记录：** 该候选后来确认存在生产写命令绕过声明 gate 的高风险缺陷，旧完成结论已经失效。以下限制不得解释为 v1.0.1 的测试结论。

日期：2026-08-08

- 至少 1 TiB 的规模是 200,000 个 NTFS 稀疏 Asset 的逻辑容量；机械硬盘吞吐和寻道校准另使用实际分配、实际读写的 2 GiB 样本。报告不会把它表述为实际写满或读取 1 TiB。
- `IFileOperation` 的最终身份复核与 Windows Shell 实际回收动作之间存在无法消除的非原子残余窗口；系统通过句柄限制、逐文件回调、结果提交和失败关闭来缩小并暴露该窗口。
- Windows 回收站不是照片备份，可能受容量、策略、清空或系统维护影响。
- SQLite 一致备份只保护应用数据库和操作证据，不是 JPG/RAF 照片备份。
- DPI 验收使用已安装候选的 WebView2 CDP device-scale/viewport 矩阵；它不能替代每一种显卡、显示器、多屏排列和第三方辅助技术的现场组合测试。
- 候选包若没有组织代码签名证书，Authenticode 状态会保持未签名；这不改变 SHA-256 绑定，但正式对外分发前应完成签名和签名后完整重测。
- 若仓库中不存在可验证的上一版本安装包，阶段 8 只能验证 schema 1–8 的逐级迁移和候选全新安装，不能把模拟旧安装声明为真实安装器升级证据。
- 为保持已测试候选及其安装路径在最终哈希复核时仍然存在，本轮没有在候选测试后执行卸载；因此“卸载后用户数据保留”没有独立的候选级破坏性证据。
- 前端测试曾在并行 runner 负载下出现一次 1 秒等待超时；相同断言在前后运行通过。冻结质量门固定为单 worker 并要求全部 38 项通过，此项归为无数据安全影响的 Low 风险测试稳定性问题。
- 所有 Import、Recycle、缓存、损坏和空间不足测试只使用生成或明确可丢弃的数据；本阶段没有对用户唯一照片执行导入、回收或删除。

真实照片 Import 和 Recycle 均继续独立关闭，必须完成单独确认清单后另行授权。
