# Gemini 第一阶段图库 UI 补丁接入

日期：2026-11-06。基础提交：8c4bc3664efe53172a336569f98d0ecfa53bf3fa。
分支：codex/ui-redesign-gemini。

接入 photo-manager-phase1-library-ui.patch，包含图库样式、文件名与日期筛选、虚拟胶片带、预览状态和缩放入口、详情分组、标记与撤销入口以及浏览上下文恢复。未修改 Rust、命令协议或依赖声明。

## 接入时修正

- 修正日期筛选类型中的冗余联合成员，统一改动文件格式。
- 预览失败卡片改为画布内绝对定位并限制高度，避免被前面的全高预览容器挤到可视区域外。
- 当前日期下最后一张照片被回收后保留日期条件及零结果，不静默扩大到全部日期。
- 增量扫描完成后恢复原照片、排序与筛选；重新绑定图库时初始化新图库的恢复上下文。
- 恢复排序请求失败时保留当前页面，避免用旧顺序冒充已恢复的排序。
- 新增回收后日期零结果、设置返回、增量扫描完成后恢复筛选照片的回归测试。
