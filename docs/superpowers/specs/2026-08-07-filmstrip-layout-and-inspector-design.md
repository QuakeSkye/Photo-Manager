# Filmstrip 尺寸、等比预览与详情栏折叠设计

日期：2026-08-07

## 1. 背景与范围

阶段 4 的图库三栏布局目前使用 `104px / 自适应 / 276px`，在最小宽度断点下使用 `96px / 自适应 / 260px`。Filmstrip 虽然已经不会横向溢出，但缩略图过小，不利于快速判断照片内容；右侧详情栏也占用了可让给缩略图和中央大图的空间。

本设计只完善已经确认的阶段 4 UI：

- 调整图库和待删除页共用的 Filmstrip 宽度、缩略图尺寸与选中反馈；
- 保证 Filmstrip 缩略图和中央大图完整等比显示，不裁切、不拉伸；
- 缩窄图库右侧详情栏，并把现有信息组织成可折叠分组；
- 保持待删除页右栏结构、删除复核规则和禁止显示的外部工具按钮不变。

本文取代以下旧约束中与本次设计冲突的部分：

- `2026-07-28-local-photo-manager-ui-design.md` 中 Filmstrip `96–112px` 的宽度范围；
- `2026-07-30-filmstrip-keyboard-bugfix-design.md` 中“不改变缩略图高度、虚拟列表步长和预览裁切方式”的限制。

不改变键盘导航、删除标记、Photoshop、文件位置、缓存、扫描、导入或删除事务。本设计不进入阶段 5。

## 2. 三栏布局

图库和待删除页继续使用三栏 Grid。桌面窗口最小宽度仍为 `1100px`，列宽规则统一为：

```css
grid-template-columns:
  clamp(160px, 15vw, 180px)
  minmax(0, 1fr)
  clamp(220px, 18vw, 260px);
```

`15% : 65% : 20%` 是最小窗口附近的目标比例，不是所有窗口宽度下的硬性比例。左栏达到 `180px`、右栏达到其响应式宽度后，新增空间优先交给中央大图。

典型结果如下：

| 窗口宽度 | Filmstrip | 中央区 | 详情栏 |
|---:|---:|---:|---:|
| 1100px | 165px | 715px | 220px |
| 1200px | 180px | 800px | 220px |
| 1440px | 180px | 约 1001px | 约 259px |

所有三栏容器继续使用 `min-width: 0`。Filmstrip 只允许纵向滚动；在任何验收窗口宽度下，`scrollWidth` 不得大于 `clientWidth`。

## 3. Filmstrip

### 3.1 尺寸与虚拟列表

Filmstrip 仍为单列纵向虚拟列表，继续只渲染可见项及少量 overscan。每个缩略图按钮使用 `106px` 固定高度，虚拟列表行步长使用 `112px`，形成 `6px` 的纵向间距。左右内边距保持 `6px`，不得因滚动条出现而把按钮推到视口外。

固定行步长是虚拟列表定位的唯一来源；组件中的定位计算与 CSS 高度必须共享同一个常量或变量，避免滚动后项目重叠、空洞或选中项定位错误。

### 3.2 完整等比显示

缩略图图片使用 `object-fit: contain`，宽高均受按钮内部预览框约束。不得使用 `cover`、固定裁切窗口或拉伸填满。横向、纵向和非标准比例照片都必须完整显示；图片比例与预览框不一致时，允许使用中性背景留白。

中央大图保持现有 `max-width: 100%`、`max-height: 100%`、`width: auto`、`height: auto` 规则，并明确使用等比 `contain` 语义。窗口缩放、详情栏折叠或 Filmstrip 变宽时都不得裁切照片边缘。

### 3.3 选中、焦点与待删除状态

图库当前项使用双层蓝色反馈：

- `2px` 主选中描边；
- 一层浅蓝色内描边；
- 白色卡片背景与轻量阴影。

待删除页当前项保持危险红色语义，并使用相同层级的双层反馈。待删除 `D` 徽标、问题项状态和非颜色文本提示保持不变。

键盘焦点必须仍然清晰可见，且不能与当前项描边相互覆盖。点击 Filmstrip 后，`D/R/←/→` 继续按既有规则立即生效；`Enter` 和 `Space` 保持按钮原生激活语义。

## 4. 图库右侧详情栏

### 4.1 固定区域

文件名和 JPG/RAF 状态始终显示在详情栏顶部。Photoshop、打开文件位置和标记/取消待删除操作继续固定在底部，不随中间详情内容滚走。按钮可用性、确认流程、错误提示和不暴露内部路径的规则不变。

待删除页不采用本节的 Accordion，不新增 Photoshop 或打开文件位置按钮；其右栏仍按已确认的复核规格呈现。

### 4.2 Accordion 分组

图库详情栏提供两个独立、默认展开且可折叠的分组：

1. **时间与文件**：拍摄日期、相机本地时间或未知时间说明、参考文件时间与总容量；
2. **照片参数**：相机型号及现有参数行。标题区显示已知相机型号摘要，没有相机型号时显示“未记录”。

分组标题使用原生 `button`，提供稳定的 `aria-controls` 和正确的 `aria-expanded`。键盘用户可用 `Tab` 定位，并用 `Enter` 或 `Space` 展开、折叠。折叠状态只保存在当前组件运行状态中，不写入设置、数据库或操作记录；重新进入图库时恢复两个分组默认展开。

详情内容区域允许纵向滚动，折叠操作不得移动底部操作区，也不得改变当前 Photo、Filmstrip 游标或键盘导航状态。

### 4.3 后续扩展边界

Accordion 内容使用清晰的分组容器和数据行结构，允许后续在“照片参数”中增加参数卡片或直方图区域。当前阶段只展示命令层已经提供的真实数据和既有“未记录”状态，不新增镜头、ISO、快门、光圈、焦距或直方图解析，不伪造示例值，也不为未来功能创建数据库字段或 Rust 命令。

## 5. 错误与边界状态

- 预览加载中、预览不可用、RAF-only、JPG-only 和 JPG+RAF 的占位状态都使用新的栏宽，但不得改变现有业务含义。
- 图片不可用时仍显示明确占位文案；不得用损坏图标或裁切后的其他资源冒充原图。
- 详情加载失败时错误提示保持可读，Accordion 不得吞掉错误信息。
- Root 离线、Photoshop 失效和外部操作进行中的禁用、提示与确认规则保持不变。
- 缩略图增加高度后，一屏可见数量会减少；虚拟列表和当前项自动保持可见规则用于抵消该取舍，不增加第二列或横向 Filmstrip。

## 6. 验证与验收

### 6.1 自动测试

- VirtualFilmstrip 组件测试覆盖 `106px` 项高度与 `112px` 行步长的一致性、虚拟定位和当前项保持可见。
- 图库交互测试先点击非当前缩略图，再直接验证 `D/R/←/→`；不得要求先点击中央大图。
- PhotoInspector 测试验证两个 Accordion 初始均展开、可独立折叠、`aria-expanded`/`aria-controls` 正确，并确认底部操作按钮不属于可折叠内容。
- 待删除视图测试确认共享的新 Filmstrip 样式生效，但 Photoshop 和打开文件位置按钮仍不渲染。

### 6.2 浏览器布局验收

在 `1100×700`、`1200×800` 和 `1440×900` 三个视口下验证图库与待删除页：

- Filmstrip 实际宽度满足 `clamp(160px, 15vw, 180px)`；
- 详情栏实际宽度满足 `clamp(220px, 18vw, 260px)`；
- Filmstrip `scrollWidth <= clientWidth`，页面不出现由三栏导致的横向滚动；
- 横向、纵向和非标准比例测试图在缩略图与中央画布中均完整可见、比例不变；
- 选中、键盘焦点、待删除和问题项反馈清楚且不互相覆盖；
- Accordion 展开与折叠不会遮挡或推动底部操作按钮离开可视区域。

### 6.3 安全与范围回归

运行现有前端、能力边界、Rust、安全审计和生产构建。测试不得导入或删除照片；不得调用 Photoshop 或其他外部程序。若以后单独进行外部程序测试，只允许使用可丢弃照片副本，并明确 Photoshop 后续写入不受本应用控制。

本次实现完成后只创建本地提交，不推送远端，并等待用户验收。
