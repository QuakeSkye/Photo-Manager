## 1. 目标

为 Gitee 仓库编写一份兼顾普通用户和开发者的中文 README。文档先帮助读者快速理解产品价值、安全边界和基本使用流程，再提供准确、可执行的源码开发、构建与测试说明。

## 2. 读者与定位

README 同时面向两类读者：

1. 普通用户：需要了解应用解决的问题、支持的照片格式、核心功能、使用流程与数据安全注意事项。
2. 开发者：需要了解技术栈、环境要求、运行方式、构建命令、测试命令和主要目录职责。

整体采用“产品优先、开发补充”的叙事顺序。项目名称使用“Fuji 照片管理器”，当前版本写为 `v1.0.2`。

## 4. 产品信息范围

产品说明仅陈述源码、配置和已提交设计文档能够证明的能力：

- 目标平台为 Windows 10/11 x64。
- 面向本地 Fuji JPG、JPEG 和 RAF 图库。
- 支持递归扫描、EXIF 时间线、JPG/RAF 保守配对、预览浏览和排序。
- 支持通过键盘浏览、待删除标记与会话内撤销。
- 支持统一复核后将照片移入 Windows 回收站，不提供永久删除降级路径。
- 支持从用户选择的来源目录进行只读预检和安全导入。
- 支持配置 Photoshop，并将 RAF 交给外部程序处理。
- 支持预览缓存、扫描报告和操作恢复状态。

README 不把规划中的未来能力描述为当前已实现功能。

## 5. 安全表述

安全说明突出以下边界：

- 扫描与浏览不会修改、移动或重命名现有照片。
- 导入过程不向来源卷写入数据，复制发布采用不覆盖既有目标的策略。
- 删除操作只使用 Windows 回收站；回收站不可用时不降级为永久删除。
- Windows 回收站不是照片备份，SQLite 数据库备份也不是照片文件备份。
- 用户仍应在独立介质上保留经过校验的照片备份，并先使用可丢弃数据验证工作流。

措辞不使用“绝对安全”“永不丢失”等无法保证的宣传语。

## 6. 开发与构建信息

开发说明以仓库当前配置为准：

- Node.js `24.x`
- Rust `1.85+`
- Windows 10/11 x64
- Tauri 2、React 19、TypeScript 5、Rust、SQLite

主要命令包括：

- `npm install`
- `npm run tauri -- dev`
- `npm run tauri -- build`
- `npm run format:check`
- `npm run lint`
- `npm test`
- `npm run test:e2e`
- `npm run test:rust`
- `npm run clippy`
- `npm run safety:audit`
- `npm run check`

构建说明明确安装包由 Tauri 的 NSIS target 生成，不声称仓库当前提供公开 Release 下载。
