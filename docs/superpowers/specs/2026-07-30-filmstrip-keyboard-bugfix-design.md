# Filmstrip 横向溢出与键盘焦点修复设计

日期：2026-07-30

## 1. 范围

本修复只处理两个图库 UI 缺陷：

1. 左侧 Filmstrip 在默认窗口尺寸下出现横向滚动条；
2. 鼠标点击缩略图后，焦点停留在缩略图按钮上，导致全局 `D/R/←/→` 快捷键被按钮过滤规则拦截。

不改变待删除事务、自动前进、撤销、照片排序、滚轮导航或阶段 5 功能。

## 2. 布局修复

- Filmstrip 继续只允许纵向滚动，明确禁止横向滚动。
- 缩略图按钮宽度根据滚动视口的实际可用宽度计算，并保留左右留白；不得再使用可能超过滚动视口客户区的固定宽度。
- 纵向滚动条出现、窗口处于 1440 × 900 或最小 1100 × 700 时，缩略图均完整显示，Filmstrip 的 `scrollWidth` 不得大于 `clientWidth`。
- 不改变缩略图高度、虚拟列表步长、选中边框、待删除徽标或预览裁切方式。

## 3. 键盘焦点修复

- 点击缩略图后保留其原生按钮焦点和可见焦点样式，不调用 `blur()`，也不把焦点强制转移到中央画布。
- 全局快捷键继续忽略输入框、选择器、文本区域、对话框及普通按钮。
- 唯一例外是事件目标位于 `.filmstrip-item`：此时 `D/R/←/→` 按现有图库或待删除视图规则执行。
- `Enter` 和 `Space` 仍保留按钮原生激活语义；快捷键 auto-repeat、修饰键、写操作进行中和对话框屏蔽规则保持不变。

## 4. 测试与验收

- 组件测试验证 Filmstrip 的横向溢出约束不会回退。
- 应用交互测试先点击非当前缩略图，再直接按 `D`，验证该 Photo 被标记且按既有规则前进；同时覆盖 `R` 和方向键仍可用。
- 浏览器在 1440 × 900 与 1100 × 700 下测量 Filmstrip `scrollWidth === clientWidth`，并目视确认缩略图未被滚动条裁切。
- 运行现有前端、能力边界、Rust、安全审计和生产构建，确认没有照片导入、物理删除或外部程序调用回归。
